# Ecommerce Sales Analysis

## Project Overview
Analyzed 51,000+ ecommerce sales records to identify sales trends, 
profitable categories, loss-making products, and business growth patterns.

## Business Questions
- Which product categories generate the highest profit?
- Which products are causing losses?
- Is the business growing year over year?
- Which customer segments contribute the most revenue?

## Data Cleaning
- Checked missing values
- Removed duplicate records
- Verified data types
- Prepared data for analysis

## Exploratory Data Analysis
- Category-wise sales and profit analysis
- Region-wise performance analysis
- Yearly sales trend analysis
- Customer segment analysis
- Correlation analysis

## Key Insights
- Technology is the most profitable category.
- Consumer segment generates the highest revenue.
- Several products are loss-making due to heavy discounts.
- Sales show consistent year-over-year growth.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Outcome
Generated actionable business insights that can help improve profitability and support data-driven decision making.
